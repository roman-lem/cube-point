# Макеты экранов (Google Stitch)

Макеты — это **референсы**, а не спецификация для попиксельного копирования. Логика и правила — в `CLAUDE.md`, стиль — в `DESIGN.md`. Если макет противоречит им, прав `CLAUDE.md` и `DESIGN.md`.

## Что игнорировать на всех макетах

Stitch регулярно дорисовывал лишнее. Не переносить в код:
- раунды, финалы, группы, судей, номера столов;
- любые упоминания WCA, «официальных» скрамблов, «регламента», «синхронизации»;
- декоративные фотографии и иллюстрации;
- выдуманные заголовки приложения («Live Results», «Taymer», «SPEEDCUBE CLUB», «Club Overview» и т. п.), футеры, номера версий, ID пользователей;
- навигацию, если она отличается от описанной в `CLAUDE.md` — использовать только её;
- даты 2024 года в примерах данных.

## Эталоны компонентов

Один и тот же элемент Stitch рисовал на разных экранах по-разному. Для каждого компонента образец берётся **только** из указанной папки, остальные макеты используются лишь для раскладки страниц.

| Компонент | Слой FSD | Эталон |
|---|---|---|
| ResultRow (свёрнутая и развёрнутая строка) | `entities/series` | `event_results` |
| AttemptSeries (серия попыток, лишние в скобках) | `entities/series` | `event_results` |
| TimeValue (время, +2, DNF, «—») | `entities/attempt` | `event_results` |
| RecordBadge (PB, LR) | `entities/record` | `event_results` |
| LiveIndicator | `shared/ui` | `event_results` |
| AppInput, AppButton | `shared/ui` | `registration` (поля — белые с рамкой, как в `DESIGN.md`, а не с заливкой) |
| Баннер встречи при входе по QR | `entities/meetup` | `registration` |
| EventCard, шапка встречи | `entities/meetup` | `meetup` |
| MeetupCard | `entities/meetup` | `club_page` |
| Блок скрамбла и управление таймером | `widgets/timer` | `timer_series` |
| Клавиатура FMC | `widgets/fmc-keyboard` | `fmc_solving` |
| Диалог подтверждения | `shared/ui` | `fmc_submit` |
| Нижняя навигация (мобильный) | `widgets/navigation` | `profile_settings` |
| Верхняя навигация (десктоп) | `widgets/navigation` | `org_competitor_desk` |
| Строка участника в списке | `entities/user` | `org_club_competitors` |
| Редактируемая таблица результатов | `widgets/results-table` | `org_meetup_desk` |
| Раскладка «список + детали» | `widgets` / `pages` | `org_competitor_desk` |

## Открытые вопросы

- Сохранение в панели организатора: на десктопе Stitch нарисовал автосохранение, на мобильном — кнопку «Сохранить». Нужно выбрать одно поведение для обеих версий (уточнить у владельца проекта).
